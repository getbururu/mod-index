# Changelog

Each version has a section, newest first. A release shows its section as its notes.

## 0.1.0

The first release.

- R2 clicks like a gun trigger and L2 has a light wall while ARC Raiders is in front; both are free while it is in the background.
- A calm lightbar colour while the game runs, or off.
- The haptics stay the game's own.
- Works on the USB cable only for now. On Bluetooth Bururu leaves the controller to the game.
- Reads only the controller: no game files, no screen, no keys.
- A page in Bururu: Effects (Triggers, Lightbar).
- Needs Bururu with mod API 0.11.
